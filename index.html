오늘 신규·퇴소 요약

일자별누적(원장님) 시트에 붙여넣는 한 줄입니다. 등록인원 = 전일등록 + 금일등록 + 금일환불. 복사는 금일등록·금일환불 2칸만 (전일등록·등록인원은 시트 수식).

① 편성현황 (신규 − 퇴소)
② 재등록 (등록 − 미등록)
편성계 = 전일편성 + 신규 − 퇴소 · 등록계 = 전일등록 + 재등록 − 환불 · 미납 = 편성계 − 등록계. 전일값은 ‘현황 저장’ 시 다음날로 이어집니다.
개강후 블록 기입 미리보기

접수 현황 (개강후 간헐 접수)

접수대장에서 오늘 날짜 접수를 전형별로 집계했어요. 유시험 합격만 수기 입력 후 대시보드의 개강후 시트 기입을 누르면 접수 블록까지 함께 반영됩니다.
유시험 접수=합격이 아니므로 합격 인원을 직접 입력하세요. (나머지 전형은 접수=합격 자동)

장학생 현황 (오늘)

오늘 장학 접수·등록·환불을 종류별로 집계했어요. 개강후 시트 기입 시 장학 블록에 함께 반영됩니다.

경영지원 현황 대조

경영지원 등록관리 앱(Supabase)의 같은 날짜 합계와 자동 비교합니다. 읽기 전용이라 그쪽 데이터는 바뀌지 않아요.
‘불러와 대조’를 누르면 경영지원 앱 값을 읽어와 비교합니다.

지난 등록 보기

날짜를 골라 그날의 등록 현황을 봅니다 (선택일까지 누적 반영). raw 로그 파일은 설정 탭에서 올려주세요.

등록/환불 추이 분석 — 전년 동기 비교

이벤트 메모 (변화 요인 기록)

등록/환불에 영향 준 이벤트를 날짜와 함께 남기면, 그래프에 보라 점선 마커로 표시돼 팀·원장님이 함께 봅니다. (예: 경쟁업체 개강, 설명회, 시험일)

지난 등록 로그 업로드

2026raw정규 시트를 CSV/엑셀로 올리면, ‘지난 등록 보기’ 탭에서 날짜를 골라 그날 현황을 볼 수 있어요.

분석용 자료 업로드 (작년 raw 로그)

작년 raw(2025raw정규) 자료를 한 번만 올리면 팀 공유(Firebase)에 저장돼, 분석 탭에서 전년 비교로 자동 표시됩니다. 올해 자료는 매일 ‘현황 저장’ 시 자동 축적돼요. 날짜의 연도를 자동 인식합니다.

개강일 & 코호트

개강일 기준으로 보고가 개강 전/후로 갈립니다. 매년 바뀌면 여기서 바꾸세요.
등록·환불이 없는 반/전형도 raw에 항상 0으로 출력됩니다. 비워두면 그날 자료에 등장한 항목만 출력해요.

재등록 집계 & 미등록 베이스라인

매달 재등록 기간이 시작되면 현재 집계월을 바꾸세요. 미등록 누적은 경영지원 앱에서 자동으로 끌어오고, 못 가져올 때만 아래 베이스라인을 씁니다.
매핑 규칙: N월분 → 정규(N−2)기(N월) · 예: 7월분 → 정규5기(7월)
베이스라인 (경영지원 연동 실패 시 폴백) — 현재 집계월 - 기준
베이스라인은 집계월마다 따로 저장됩니다. 7월분으로 바꾸면 7월 베이스라인을 새로 입력하세요.

장학 코드 매핑

일일명단 장학 칸의 코드(예: Q⑥_50)를 리포트 장학 줄에 연결합니다. 한 줄에 여러 코드는 쉼표로 구분. 해마다 코드가 바뀌면 여기만 고치면 됩니다.
비워두면 그 줄은 집계 안 됨. 매핑 안 된 코드는 처리 시 ‘미매핑’으로 경고합니다.

팀 비밀번호

팀원이 입장할 때 쓰는 비번입니다. 평문이 아니라 해시로만 저장돼요.

Firebase 연결

팀 공유 저장소. config 객체를 붙여넣고 저장하면 이 브라우저에 기억됩니다. (배포 시엔 index.html 상단 상수에 직접 넣어도 됩니다.)
⚠ API 키는 도메인 제한(HTTP referrer)을 꼭 거세요. 규칙은 request.auth != null 기준이며 if true를 쓰지 않습니다.
